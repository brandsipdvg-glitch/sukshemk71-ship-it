SoundShare

True peer-to-peer data transfer over the air. Your message never touches a network — it travels purely as audio between a speaker and a microphone.

How it works

  • Text is UTF-8 encoded to bytes, then to bits (or 2–bit "quads").
  • ⚡ Fast uses four tones (1100 · 1800 · 2500 · 3200 Hz) at 15 ms each — a "Hello World" transfers in about 1.5 s.
  • 🐢 Slow uses classic 1000/2000 Hz FSK at 100 ms per bit — slower, but more robust in noisy rooms.
  • The transmitting page plays the tones through its speaker.
  • The receiving page listens, auto-detects which mode is on air, demodulates both streams back to bits, checks the CRC32, and shows your message.

No internet, no server, no Bluetooth, no Wi-Fi, no QR codes. The sound itself is the data link. See the README for the full packet protocol.
